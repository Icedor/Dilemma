# Clear controls and local Lucide icons

The waiting action was visually too similar to a heading. It is now a full-width switch with a stable accessible name, visible On/Off state, a sliding thumb and a border. The server response determines the state. Pending requests disable duplicate actions; errors preserve the previous state and expiry returns the switch to Off. Notification checkboxes use the same visual switch family and retain native form behavior. The saved choice is applied through each form's existing submit action.

Actions such as copy, share, install, reconnect, revoke and export have local Lucide SVG icons alongside visible labels. Text actions have a button outline. Navigational text links retain underlines and directional icons. Native disclosures use a consistent chevron and generous focus/click area. Pointer feedback, keyboard focus, reduced-motion and forced-color rules are included.

The owner requested a chosen icon library. Lucide was selected for its consistent outlined shapes and small SVG subset. Fifteen icons are bundled in one local document sprite, with no runtime package or remote request. The upstream revision is 1980e3d59b0fa1a2aeb566d5902b25ee98204001. The original ISC/Feather MIT notices are included in [LUCIDE_LICENSE.txt](LUCIDE_LICENSE.txt) and the release package. [Upstream license](https://lucide.dev/license).
